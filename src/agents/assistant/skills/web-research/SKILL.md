# Do a web research answer

1. Search with `websearch`, 5–10 results. Prefer primary and authoritative sources
   (official documentation, encyclopedias, journals, the subject's own site) over
   aggregators and SEO pages.
2. Open at most the 2–3 most promising results with `fetch`; read them before
   answering. Do not fetch everything.
3. Answer from what you read, not from memory alone. When sources disagree, say so
   and name each side.
4. Structure the answer: a one-line answer first, then the detail in short sections.
   Cite each claim with a link to its source.
5. Mark time-sensitive facts (dates, versions, prices, news) with their recency.
6. Say what you could not verify. Never invent a URL or a citation.
